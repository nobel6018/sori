# 우클릭 메뉴

사이드바의 녹음 항목을 우클릭하면 그 녹음에 할 수 있는 동작을 OS 메뉴로 띄운다. 녹음을 열지 않고도 처리, 요약, 내보내기, 삭제가 된다.

## 코드 위치

| 무엇 | 어디 |
|---|---|
| 메뉴 항목과 동작 | `src/recordingMenu.ts` `showRecordingMenu` |
| 항목 우클릭 받기 | `src/components/Sidebar.tsx` `onContextMenu` |
| 처리, 삭제 후 목록 갱신 | `src/App.tsx` `<Sidebar onContextMenu>` |
| 웹뷰 기본 메뉴 끄기 | `src/main.tsx` |

## 항목

| 항목 | 켜지는 상태 | 동작 |
|---|---|---|
| 받아 적기 / 기본 설정으로 다시 받아 적기 | 녹음 중, 처리 중이 아닐 때 | `processDefaults`. 언어는 설정값, 화자 수는 자동. 자동 요약, AI 정리 설정을 따른다 |
| 처리 취소 | 처리 중일 때만 보임 | `cancel_processing` |
| 요약하기 | 완료 | 기본 제공자와 기본 템플릿으로 `summarize_recording` |
| AI로 제목, 태그 다시 정리 | 완료 | `organize_recording` (force). 손으로 고친 태그는 덮지 않는다 |
| 마크다운으로 복사 | 완료 | 녹음 화면의 "마크다운 복사"와 같은 내용 |
| 내보내기 > 형식 | 완료 | 저장 창을 띄운다 (`docs/export.md`) |
| Finder에서 보기 (윈도우는 탐색기) | 녹음 중이 아닐 때 | `reveal_audio` |
| 삭제… | 녹음 중, 처리 중이 아닐 때 | 확인 창 뒤 `delete_recording`. 보고 있던 녹음이면 빈 화면으로 |

화자 수나 언어를 바꿔 처리하려면 녹음을 열어 처리 설정에서 한다. 메뉴는 기본값으로만 처리한다.

## 웹뷰 기본 메뉴

배포 빌드에서는 웹뷰 기본 메뉴("다시 불러오기")를 막는다. 누르면 화면이 새로 불려 열어 둔 상태가 사라지기 때문이다. 글 입력 칸과 글을 선택한 상태에서는 복사, 붙여넣기 메뉴가 필요해 그대로 둔다. 개발 빌드(`pnpm tauri dev`)는 요소 검사를 쓰려고 막지 않는다.
