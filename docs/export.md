# 내보내기

녹음 화면의 "내보내기"에서 고릅니다(`src/export.ts`). 저장 창에서 고른 경로에 백엔드가 그대로 씁니다(`save_export`).

| 형식 | 내용 |
|---|---|
| 마크다운 (.md) | 제목, 날짜, 길이, 참석자, 최근 요약, 메모, 전사. "마크다운 복사"와 같은 내용 |
| 텍스트 (.txt) | `[0:12] 이름: 내용` 형식의 전사 |
| 자막 SRT (.srt) | 발화 하나가 자막 한 칸. 줄 앞에 화자 이름 |
| 자막 WebVTT (.vtt) | SRT와 같고, 화자는 `<v 이름>` 태그로 넣어 플레이어가 따로 보여 줄 수 있음 |
| Word (.docx) | 제목, 요약(제목, 목록, 굵은 글씨 서식 유지), 메모, 화자별 전사 |

자막 한 칸이 84자를 넘으면 문장 경계에서 나누고, 시간은 글자 수 비율로 나눕니다. whisper 발화는 30초까지라 그대로 쓰면 화면을 가립니다. DOCX를 만드는 `docx` 라이브러리는 내보낼 때만 불러와 앱 시작을 늦추지 않습니다.
