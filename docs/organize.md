# 태그로 모아 보기, AI 정리, 녹음한 곳

녹음을 태그로 모아 보고, Mac이 받아 적은 녹음을 AI로 정리(제목, 태그, 할 일)하고, 녹음을 시작한 곳을 남깁니다(0.8.0). 캘린더 일정 연결, 할 일을 미리 알림으로, 태그 범위 질문, iPhone 미리 전사는 0.9.0에 더했습니다.

## 태그

폴더와 태그를 따로 두지 않고 태그 하나로 분류합니다. 태그 이름에 `/`를 넣으면 계층이 생겨 폴더처럼 모아 봅니다.

```
업무/영업/한빛로보틱스
업무/주간회의
개인/병원
```

- 한 녹음에 태그를 여러 개(최대 10개) 붙일 수 있습니다. "고객 미팅"이면서 "주간회의"인 녹음은 두 곳에 다 보입니다
- 상위 태그(`업무`)를 고르면 하위 태그(`업무/영업/...`)가 붙은 녹음도 보입니다
- 정리 규칙: 앞뒤 공백, `/` 앞뒤 공백, 빈 단계(`업무//영업`), 머리의 `#`을 없애고, 대소문자만 다른 태그는 하나로 칩니다(`sori_sync::tags::normalize_tags`, `src/tags.ts` `normalizeTags`)

| 화면 | Mac | iPhone |
|---|---|---|
| 목록 | 사이드바 위 태그 트리(`TagTree`). 누르면 걸러 보고, 고른 태그는 다음 실행에도 기억. "태그" 머리줄을 누르면 트리 전체를 접고(0.9.8), 접힌 상태에서도 고른 태그를 머리줄에 보임 | 목록 위 태그 칩 줄(`List.tsx` `TagBar`). 하위가 있는 태그를 누르면 그 안으로 들어감 |
| 녹음 | 제목 아래 태그 편집(`TagEditor`), 녹음한 곳 | 날짜 아래 태그 편집, 녹음한 곳 |
| 찾기 | 빠른 찾기(⌘K)가 제목, 태그, 장소를 초성으로도 찾음(`search.rs` `matches_with_initials`) | 태그 입력 자동완성이 초성으로 찾음 |

태그 입력은 Enter나 쉼표로 붙이고, 칩의 ×나 빈 칸에서 Backspace로 뺍니다. 자동완성은 화살표로 고른 경우에만 그 제안을 붙이고, 아니면 친 글자 그대로 새 태그가 됩니다.

## AI 정리 (Mac)

받아 적기가 끝나면(자동 요약이 켜져 있으면 요약 뒤에) 요약과 같은 CLI(claude 또는 codex) 한 번으로 제목, 태그 1~3개, 할 일 후보를 받습니다(`tagger.rs`, `lib.rs` `organize_recording`). 설정 > "받아 적기가 끝나면 AI로 정리하기"(기본 켜짐). 녹음 화면의 "AI로 다시 정리"로 다시 할 수 있습니다.

- 제목: 앱이 붙인 기본 제목("녹음 2026-10-31 12:00")이고 사람이 고친 적 없을 때(`titleEditedAt`)만 바꿉니다. AI가 고른 캘린더 일정이 있으면 그 제목을 참고합니다
- 할 일: 대화에서 분명히 정한 일만, 최대 10개. 기한은 녹음 날짜 기준으로 YYYY-MM-DD로 바꿉니다. 후보로만 두고(`todos.json`, 이 Mac에만), 녹음 화면의 할 일 후보에서 고르고 고친 것만 "미리 알림에 넣기"를 눌러야 미리 알림의 기본 목록에 들어갑니다(`calendar.rs` `add_reminders`). 넣은 것은 "넣음"으로 남고 다시 정리해도 지우지 않습니다

- 태그: 녹음을 서로 나눠 모아 볼 수 있는 이름(거래처나 기관, 프로젝트, 주제)을 고릅니다. 예: `HD현대`, `데이터센터`. 계층은 `HD현대/슈컴센터`처럼 정말 하위 관계일 때만, 2단계까지
- "업무", "주제", "기타"처럼 거의 모든 녹음에 붙는 포괄 분류는 쓰지 않습니다. 0.9.3까지는 지시문 예시(`업무/영업/한빛로보틱스`)를 따라 AI가 모든 녹음에 `업무/…`, `주제/…`를 붙여, 사이드바의 "업무 5"가 전체와 같았습니다. 0.9.4부터 지시문에서 빼고, AI 답과 쓰던 태그 목록에서도 맨 앞 포괄 분류를 코드로 걷어 냅니다(`tagger.rs` `GENERIC_ROOTS`, `strip_generic`). 사람이 붙인 태그는 건드리지 않습니다
- 사이드바와 iPhone 태그 줄은 모든 녹음에 붙은 상위 태그를 건너뛰고 하위 태그를 바로 보입니다(`src/tags.ts` `liftUniversal`). 걸러 내는 힘이 없는 줄을 보이지 않으려는 것입니다
- 다른 녹음에 쓰인 태그와 녹음 수를 함께 넘겨 쓰던 태그를 먼저 고르게 합니다. 태그가 마구 늘지 않게 하려는 것입니다
- 넘기는 내용: 제목, 날짜, 장소, 메모, 요약(있으면), 전사 일부(요약이 있으면 앞 3천 자, 없으면 앞 8천 자와 뒤 4천 자)
- 사람이 태그를 고친 녹음(`tagsEditedAt`)은 건드리지 않습니다. AI가 도는 사이 고쳐도 저장 직전에 다시 확인해 지킵니다
- 한 번 정리한 녹음(`autoTaggedAt`, 이름은 0.8.0 그대로)은 자동으로 다시 하지 않습니다. 녹음 화면에 "AI" 표시가 붙고, 태그를 고치면 사라집니다
- iPhone에서 동기화로 새로 온 녹음도, 자동 처리가 켜져 있으면 받아 적고 분류합니다(`App.tsx` `onRecordingsSynced`). 업데이트 전부터 대기 중이던 녹음은 건드리지 않습니다
- 설정의 "예전 녹음에 AI 제목, 태그, 할 일 붙이기"는 하나씩 차례로 정리합니다(한꺼번에 돌리면 구독 사용량 한도에 금방 걸린다). "붙이기"는 받아 적기가 끝났고 아직 정리하지 않은 녹음만, "모두 다시 붙이기"는 받아 적기가 끝난 모든 녹음을 지금 규칙으로 다시 정리합니다(`force`). 다시 붙여도 손으로 고친 제목과 태그, 미리 알림에 넣은 할 일은 지킵니다. 요약은 만들지 않습니다. 일은 화면 밖(`src/bulkOrganize.ts`)에서 돌아 설정 창을 닫아도 이어지고, 설정 줄과 사이드바 아래에 "3/5번째 정리 중 · #3 제목 · 25초"와 멈추기 버튼이 보입니다(`BulkProgress.tsx`). 멈추기는 지금 녹음이 끝난 뒤 멈추고, 앱을 끄면 지금 녹음에서 멈춥니다. 끝난 녹음은 그대로 남습니다
- 대화에 회사 이름이 직접 나오지 않으면 AI는 회사 태그를 붙이지 않습니다(추측 금지). 같은 날 이어진 방문처럼 대화 밖의 사실은 손으로 태그를 붙입니다. 손으로 붙인 태그는 AI가 덮어쓰지 않고, 다음 정리 때 "쓰던 태그"로 참고합니다

### 캘린더 일정

정리할 때마다 녹음 구간(앞뒤 10분 여유)과 겹치는 일정을 많이 겹치는 순으로 최대 5개 찾습니다. 종일 일정은 뺍니다(`calendar.rs` `events_for`). 시간이 겹친다고 그 일정의 녹음은 아닙니다. 같은 시간에 일정이 둘이면 하나는 가지 않았고, 일정을 비우고 다른 일을 했을 수도 있습니다(10월 29일 클리마데이 일정 시간에 실제로는 HD현대중공업 미팅을 녹음했는데 0.9.3까지 클리마데이로 붙었다). 그래서 후보를 번호와 함께 AI에 넘기고, 대화에 그 일정의 회사, 행사, 사람, 주제가 분명히 나올 때만 고르게 합니다(`tagger.rs` `build_prompt`, 답의 `event`). 확실하지 않으면 고르지 않고, 고르지 않은 일정의 이름은 제목과 태그에 쓰지 않습니다. 고른 일정만 `event`에 남기고, 고르지 않았으면 비웁니다. 캘린더 쓰기를 끈 상태면 `event`를 건드리지 않습니다. 고른 일정의 참석자(나 빼고)는 화자 이름 입력의 자동완성 후보로 띄웁니다. iPhone 캘린더도 iCloud로 Mac에 보이므로 iPhone 녹음도 Mac에서 짝지어집니다. 설정 > "정리할 때 캘린더 일정 쓰기"(기본 켜짐). 처음에 macOS가 캘린더 허락을 묻고, 미리 알림은 처음 넣을 때 따로 묻습니다

## 태그로 좁혀 묻기

⌘J 질문 창의 범위에서 태그를 고르면 그 태그(하위 포함)가 붙은 녹음에만 묻습니다. 모든 녹음에 물을 때 15만 자 상한에 오래된 녹음이 잘리는 것을 막습니다(docs/ask.md)

## iPhone 미리 전사

iOS 26 이상에서 녹음을 기기 안에서 바로 받아 적습니다(`SpeechAnalyzer`, `plugin/ios/Sources/Transcribe.swift`). 화자는 나누지 않습니다.

- 앱이 화면에 있는 동안 전사가 없는 녹음을 하나씩 처리합니다(`mobile/src/App.tsx`). 긴 전사는 백그라운드에서 끊길 수 있어서입니다. 상세 화면의 "iPhone에서 바로 전사"로 직접 할 수도 있습니다
- 결과는 `preview-transcript.json`에 Mac 전사와 같은 모양으로 두고, 이 iPhone에만 둡니다(동기화 대상이 아님)
- Mac 전사(`transcript.json`)가 오면 그것을 보여 줍니다. Mac은 미리 전사와 상관없이 지금처럼 전사하고 화자를 나눕니다
- 기기 언어로 전사하고, 지원하지 않으면 한국어로 합니다. 언어 모델이 없으면 처음 한 번 받습니다
- 설정 > "iPhone에서 바로 미리 전사"(기본 켜짐). iOS 26 미만에서는 하지 않습니다
- 분류가 실패해도 알림을 띄우지 않고 개발자 콘솔에만 남깁니다. 분류는 덤이라 받아 적기와 요약을 방해하지 않습니다

## 녹음한 곳

녹음을 시작할 때 위치를 한 번 받아 주소로 바꿔 남깁니다. 녹음 내내 추적하지 않습니다. 기기마다 설정에서 끕니다(기본 켜짐).

| | iPhone | Mac |
|---|---|---|
| 위치 | GPS, Wi-Fi, 기지국(`requestLocation`, 최대 10초) | Wi-Fi(`CLLocationManager`, 최대 10초, 오차 100m 이하면 바로 끝) |
| 주소 | `CLGeocoder`(최대 8초) | `CLGeocoder`(최대 8초) |
| 권한 | "앱을 사용하는 동안". 처음 묻는 것은 앱 화면에서 녹음할 때만. 동작 버튼으로 시작하면 못 받을 수 있음 | 시스템 설정 > 개인정보 보호 및 보안 > 위치 서비스. 처음 녹음할 때 묻는 동안 시간이 지나면 다음 녹음부터 남음 |
| 설정 | 앱 설정 > "녹음할 때 위치 남기기"(`preferences.json`) | 설정 > "녹음할 때 위치 남기기"(`Settings.record_location`) |

- 위치를 못 받으면 조용히 건너뜁니다. 녹음은 그대로 됩니다
- 대신 Mac 설정 화면이 못 남기는 이유를 알립니다(0.9.8, `location.rs` `status`, `SettingsDialog.tsx` `LocationHint`). Mac 전체 위치 서비스가 꺼져 있으면(`locationServicesEnabled` false) sori는 허락을 물을 기회조차 없이 건너뛰어, 0.8.0부터 Mac 녹음에 위치가 하나도 남지 않았는데 알 길이 없었습니다. "위치 서비스 열기"는 시스템 설정의 위치 서비스 화면을 엽니다
- 터미널에서 같은 방식으로 상태를 보려면 `cargo run --example location_check`(작업 스레드), `... -- main`(메인 스레드). 터미널 앱의 권한으로 돌기 때문에 sori 앱의 허락 여부는 알 수 없고, 위치 서비스가 켜졌는지와 위치가 오는지만 봅니다
- Mac은 2분 넘은 위치를 쓰지 않습니다. 노트북을 옮긴 뒤 예전 장소가 찍히지 않게 하려는 것입니다
- Mac 앱은 개발자 인증서 없이 서명(ad-hoc)해 업데이트마다 서명이 바뀝니다. macOS가 위치 허락을 다시 물을 수 있습니다
- `CLGeocoder`는 macOS 26, iOS 26에서 MapKit으로 대체 표시됐지만, 그 API는 26부터라 최소 지원 버전(macOS 14.2, iOS 18)에서 쓸 수 없어 그대로 씁니다
- 장소를 누르면 Apple 지도로 엽니다. iPhone은 화면(WebView) 안에서 열면 앱 화면이 지도 페이지로 바뀌어 `UIApplication.open`으로 엽니다(`open_url`)

## meta.json 필드

| 필드 | 뜻 | 쓰는 쪽 |
|---|---|---|
| `tags` | 태그 목록 | 사람(두 기기), AI(Mac) |
| `tagsEditedAt` | 사람이 태그를 고친 시각. 있으면 AI가 덮어쓰지 않음 | 두 기기 |
| `autoTaggedAt` | AI가 정리한 시각 | Mac |
| `titleEditedAt` | 사람이 제목을 고친 시각. 있으면 AI가 제목을 바꾸지 않음 | 두 기기 |
| `event` | `{ title, start, end, attendees, calendar }` 겹치는 캘린더 일정 | Mac |
| `location` | `{ lat, lon, accuracy, place, capturedAt }` | 녹음한 기기 |

모두 기기끼리 나눕니다(`crates/sori-sync/src/meta.rs` `SHARED`). 이 목록에 없는 필드는 클라우드에 올리지 않으므로, 예전 앱이 녹음을 고치면 새 필드가 빠집니다. Mac과 iPhone을 같은 버전으로 함께 올립니다.
