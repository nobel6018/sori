# 가져온 파일의 녹음 시각

파일을 가져오면 `createdAt`은 가져온 시각이 된다. 다른 기기로 녹음한 파일은 실제 녹음 시각과 며칠씩 차이 날 수 있어, 찾을 수 있으면 `recordedAt`에 실제 녹음 시작 시각을 따로 남긴다(0.15.0).

| 쓰는 곳 | 기준 |
|---|---|
| 목록, 상세, 빠른 열기, 내보내기에 보이는 날짜 | `recordedAt`이 있으면 그것, 없으면 `createdAt` (`startedAt()`, src/api.ts) |
| 캘린더 일정 찾기, AI 태그와 질문에 넘기는 날짜 | 같음 (`Recording::started_at`, src-tauri/src/store.rs) |
| MCP `list_recordings`의 since/until, Raycast | 같음 |
| 목록 순서, 녹음 번호 | `createdAt` 그대로. 가져온 순서대로 쌓여 방금 가져온 녹음이 맨 위에 온다 |

## 찾는 순서

코드: `src-tauri/src/recorded_at.rs` (`detect`, `from_file_name`, `from_mp4`)

1. 파일 이름. 녹음기가 녹음을 시작할 때 붙인 시각이라 가장 정확하다. 시각까지 있어야 쓰고, 날짜만 있으면 쓰지 않는다
   - 갤럭시 녹음기 `음성 261106_142115.m4a`, `통화 녹음 홍길동_261106_142115.m4a`
   - `Recording_20261030_143015`, `20261030 143015-ABCD`(iPhone 음성 메모 원본), `REC20261030143015`
   - `2026-10-30 14-30-15`, `2026.10.30 14.30`
   - macOS 화면 기록 `2026-10-30 at 2.30.15 PM`, `2026-10-30 오후 2.30.15`
   - Zoom `GMT20261030-053015`는 UTC, 나머지는 이 Mac의 현지 시각으로 본다
2. mp4(m4a, mov) 헤더 `mvhd`의 만든 시각에서 길이를 뺀 값. 녹음기는 파일을 닫을 때 이 시각을 적는다. 갤럭시 녹음기 파일로 확인하니 이름의 시작 시각 + 길이와 30초 안으로 맞았다. 녹음 중 일시정지했다면 그만큼 앞당겨진다(#32는 12분). 그래서 이름보다 뒤로 둔다
3. 둘 다 없으면 남기지 않는다. 파일 수정 시각은 복사, AirDrop 때 바뀌어 쓰지 않는다

2000년 전이거나 지금보다 하루 넘게 뒤인 값은 버린다(헤더가 0으로 비어 1904년이 나오는 파일이 있다).

## 0.14.1 이하에서 가져온 녹음

앱을 시작할 때 `Store::fill_recorded_at`이 `recordedAt`이 없는 가져온 녹음을 다시 본다. 가져온 녹음인지는 트랙이 없고 `sourceName`에 확장자가 있는지로 가른다(앱 녹음은 "마이크 녹음", "iPhone"). 원래 파일 이름이 `sourceName`에 남아 있어 원본 없이도 찾는다.

## 동기화

`recordedAt`은 기기끼리 나누는 필드다(crates/sori-sync/src/meta.rs `SHARED`). 0.14.x 앱이 이 녹음을 고치면 클라우드에서 빠지므로 Mac과 iPhone을 함께 올린다. 빠져도 다음에 Mac이 시작할 때 다시 채운다.
