# 화자 목소리 기억

화자 이름을 바꾸면 그 사람의 목소리 특징을 기억합니다. 다음 녹음에서 비슷한 목소리가 나오면 같은 이름을 자동으로 붙입니다. 목소리 특징은 이 컴퓨터의 `voices.json`에만 있고, 요약이나 질문을 보낼 때도 넘기지 않습니다.

| 위치 | 하는 일 |
|---|---|
| `src-tauri/src/engine/voiceprint.rs` `speaker_embeddings` | 처리할 때 화자마다 가장 긴 구간 8개(1.5초 이상, 가운데 10초까지)의 임베딩 평균을 만든다. 전사 파일의 `speakerEmbeddings`에 저장 |
| `src-tauri/src/voices.rs` `VoiceBook` | 이름별 표본(최대 12개)을 모으고, 새 녹음의 화자와 맞춰 본다 |
| `src-tauri/src/lib.rs` `name_speaker` | 이름을 바꾸면 표본을 더한다. 예전에 다른 이름으로 알아본 화자였다면 그쪽 표본을 뺀다 |
| `src-tauri/src/lib.rs` `process_recording` | 처리가 끝나면 기억한 목소리와 맞춰 이름을 붙인다 |

## 맞추는 방법

- 목소리마다 표본 평균(중심)을 내고, 새 화자의 특징과 코사인 유사도를 잽니다
- 유사도 0.6(`voices::THRESHOLD`) 이상인 쌍을 높은 순서로 짝짓습니다. 한 목소리는 한 화자에게만 붙습니다
- 이미 이름이 있는 화자(마이크 쪽 "나")는 건너뜁니다

기준값은 3D-Speaker ERes2Net 임베딩으로 쟀습니다. 5분 30초 녹음을 앞뒤로 나눠 비교하니 같은 사람 0.99, 다른 사람 0.18~0.19였습니다(`cargo run --release --example voices_check -- <녹음 폴더> <임베딩 모델>`). 이 녹음은 TTS 목소리라 같은 사람 값이 실제보다 높게 나옵니다. 사람 목소리는 마이크와 방이 바뀌면 값이 내려가므로 기준값에 여유를 두었습니다. 실제 녹음에서 엉뚱한 이름이 붙거나 아는 사람을 못 알아보면 이 값을 조정합니다.

## "나"

마이크와 시스템 소리를 함께 녹음하면 마이크 쪽 화자가 한 명일 때 "나"로 이름을 붙입니다. 이 화자는 본인이 확실하므로 "나"의 목소리로 자동 기억합니다. 그래서 가져온 파일에서도 본인을 알아봅니다.

## 끄기와 지우기

설정의 "화자 목소리 기억하기"를 끄면 기억하지도, 이름을 붙이지도 않습니다. 기억한 목소리는 설정에서 이름을 바꾸거나 잊을 수 있습니다. 0.3.0 이하에서 처리한 녹음은 목소리 특징이 없어서, 이름을 바꿀 때 오디오를 다시 읽어 특징을 뽑습니다. 1시간 녹음이면 몇 초 걸립니다.
